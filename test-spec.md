# Test Specification

## Requirements

Build a task management system with the following features:

- Users can create tasks
- Tasks have priorities
- Users can assign tasks to team members
- Tasks can have due dates
- System should send notifications

## User Stories

- As a user, I want to create tasks so I can track my work
- As a user, I want to set priorities so I know what's important
- As a manager, I want to assign tasks to team members
- As a user, I want to set due dates
- As a user, I want to receive notifications about my tasks
